# 80portisfound.github.io

Personal portfolio and technical blog powered by Jekyll and GitHub Pages.

## Local development

```bash
bundle install
bundle exec jekyll serve
```

Open `http://127.0.0.1:4000`.

## Structure

- `index.html` — portfolio home
- `blog/index.html` — blog index
- `_posts/` — Markdown articles
- `_layouts/` — shared blog templates
- `assets/css/blog.css` — blog styling
